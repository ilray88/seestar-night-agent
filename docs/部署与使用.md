# Seestar S30 Pro · 开源 Agent 控制方案（部署与使用手册）

> 适用设备：**ZWO Seestar S30 Pro**（固件 9.75，安卓 App V3.4.0）
> 适用平台：**Windows**（本机已部署完成）
> 本方案让你用**自然语言**通过 AI Agent（opencode）控制望远镜：
> 连接、GOTO 目标、自动对焦、实时叠加、数据质检、观测规划、远程关机……

## 一、这套方案是什么（架构图）

```
 ┌─────────────────────────────────────────────────────────────┐
 │  你（自然语言）                                               │
 │  "帮我看一下 M31 能不能拍，能拍就 goto 并开始叠加"            │
 └───────────────────────────┬─────────────────────────────────┘
                             ▼
 ┌─────────────────────────────────────────────────────────────┐
 │  AI Agent（opencode · 本机已在运行）                          │
 │  ── 推理 / 调用工具 / 读文档（Skills）                        │
 └───────────────────────────┬─────────────────────────────────┘
                             ▼  MCP 协议（stdio，本机）
 ┌─────────────────────────────────────────────────────────────┐
 │  seestar-mcp   ← 你刚部署的"Agent 接口层"                     │
 │  34 个工具：控制 / 状态 / 数据 / 质检QA / 观测规划 / 项目历史  │
 └───────────────────────────┬─────────────────────────────────┘
                             ▼  HTTP（Alpaca 协议，本机 :5555）
 ┌─────────────────────────────────────────────────────────────┐
 │  seestar_alp（SSC 简易 Seestar 控制器）← "设备桥接层"         │
 │  · 负责与望远镜握手、维持连接、心跳、重连                     │
 │  · 自带网页界面 http://localhost:5432（可手动操作）           │
 └───────────────────────────┬─────────────────────────────────┘
                             ▼  JSON-RPC（TCP :4700，需 RSA 密钥认证）
 ┌─────────────────────────────────────────────────────────────┐
 │  Seestar S30 Pro（望远镜本体，你家 WiFi 内）                  │
 └─────────────────────────────────────────────────────────────┘
```

**为什么要两层？**
- `seestar_alp` 是老牌开源项目，把望远镜的私有 JSON-RPC 协议封装成标准的 ASCOM Alpaca 接口，还提供现成的网页操作界面；
- `seestar-mcp` 是新项目，在 Alpaca 之上再包一层 **MCP（Model Context Protocol）**，让 AI 能"看懂并调用"。它自带观测规划、天气评估、出图质检（QA）等**为 Agent 设计的**能力。

## 三、RSA 密钥（✅ 本次已自动完成）

> **状态：已完成。** 密钥已提取并放置到位：
> - 文件：`C:\Users\BGSJIA\seestar-agent\seestar_alp\seestar_client_key.pem`（932 字节，RSA 1024-bit PKCS#8）
> - 来源：APKPure 后端 API 下载的官方 **Seestar v3.4.0 XAPK**（1.45 GB，已存于 `_Seestar_3.4.0.xapk`，可删）
> - 使用 `seestar_alp` 自带的 XAPK 感知提取器 `python -m emulator.firmware.extract_pem` 提取
>
> 若将来换设备/换固件导致认证失效，用下面的方法重新提取即可。

### 为什么必须做

Seestar 固件 **7.18 及以后**（你的 9.75 属于此列）给本地控制接口加了 **RSA 挑战-应答认证**。
望远镜会先让你签名一段随机字符串，签名对了才接受命令。
**没有正确密钥时，表现极具迷惑性**：

> socket 连得上、事件流也在滚、界面看起来"已连接"，
> 但**每一条命令都超时、没有任何响应**，日志里报 `Unable to get stats.`

这不是故障，是**缺密钥**。官方已确认此现象根因就是 "missing pem"。

### 密钥从哪来

望远镜出厂时，官方 App（APK）与设备共享**同一把 RSA 私钥**。这把私钥以**明文**形式嵌在官方 APK 的 `lib/arm64-v8a/libopenssllib.so` 里。

因此：**从你自己合法拥有的官方 Seestar APK 中提取一次即可**。该密钥是全局统一的，长期有效，不用为每台设备单独提取。

> 法律依据：US DMCA §1201(f) 互操作豁免；EU 软件指令 2009/24/EC 第 6 条。
> 这是开源社区（seestarpy、seestar_alp 等）公认的标准做法。**本文档不构成法律意见。**

### 重新提取的方法（已验证可用）

**第 1 步：下载官方 XAPK**

APKPure 网页版有 Cloudflare 拦截，**必须走它自家 App 的后端 API**：

```powershell
$h = @{
  'x-cv'   = '3172501'
  'x-sv'   = '29'
  'x-abis' = 'arm64-v8a,armeabi-v7a,armeabi,x86,x86_64'
  'x-gp'   = '1'
}
$r = Invoke-WebRequest -Headers $h -UseBasicParsing `
  'https://api.pureapk.com/m/v3/cms/app_version?hl=en-US&package_name=com.zwo.seestar'
$txt = [System.Text.Encoding]::GetEncoding(28591).GetString($r.RawContentStream.ToArray())
[regex]::Matches($txt, 'https://download\.pureapk\.com/b/XAPK/[^\x00-\x20\x7f-\xff]+') |
  ForEach-Object { $_.Value } | Sort-Object -Unique
```

从输出中挑 `versionCode=149`（即 v3.4.0）那条，用 `curl -L` 下载（**必须跟随跳转**）：

```powershell
curl.exe -L --max-time 900 -o _Seestar_3.4.0.xapk "<上面那条URL>"
```

**第 2 步：提取密钥（自写工具已支持嵌套 XAPK）**

```powershell
cd C:\Users\BGSJIA\seestar-agent
python extract_pem.py _Seestar_3.4.0.xapk -o seestar_alp\seestar_client_key.pem
```

输出 `[+] 在 config.arm64_v8a.apk!lib/arm64-v8a/libopenssllib.so 中找到 1 个密钥块` 即成功。
（已验证：与 seestar_alp 官方提取器结果逐字节一致。）

备用方式（seestar_alp 自带模块）：

```powershell
cd C:\Users\BGSJIA\seestar-agent\seestar_alp
.\.venv\Scripts\python.exe -m emulator.firmware.extract_pem --apk ..\_Seestar_3.4.0.xapk --out seestar_client_key.pem
```

**第 3 步：验证密钥格式**

```powershell
.\.venv\Scripts\python.exe -c "from cryptography.hazmat.primitives import serialization as s; k=s.load_pem_private_key(open('seestar_client_key.pem','rb').read(),None); print(type(k).__name__, k.key_size)"
```

应输出 `RSAPrivateKey 1024`。

> 注：`extract_pem.py` 现已支持两种格式：单文件 APK 与嵌套 split APK 的 XAPK。
> 备选：**bguthro/seestar-tool** 桌面程序有 "Extract PEM Key" 按钮，选 APK 一键导出。

## 四、网络连接：让电脑与望远镜"在同一个网"（关键）

望远镜有两种工作模式，二选一：

### 方案 A：站模式（Station Mode）— **推荐**

1. 用官方手机 App，在设置里让望远镜**加入你家 WiFi**（和你电脑同一个路由器）；
2. 登录路由器后台，给望远镜分配一个**固定 IP**（DHCP 静态租约），例如 `192.168.20.50`；
3. 编辑 `seestar_alp\device\config.toml`，把那台设备的
   `ip_address = "seestar.local"` 改成你的固定 IP：
   ```toml
   [[seestars]]
   name = "Seestar S30 Pro"
   ip_address = "192.168.20.50"
   device_num = 1
   ```
4. 同步修改 `seestar-mcp\.env` 里的 `SEESTAR_SEESTAR_HOST` 为同一 IP。

优点：手机和电脑可**同时**连接，望远镜也能上网（远程/OTA）。

### 方案 B：AP 模式（直连望远镜自带热点）

1. 让望远镜进入 AP 模式（广播自己的 WiFi）；
2. **电脑**连接望远镜的 WiFi（注意：连上后电脑会暂时断网）；
3. 望远镜的 IP 通常是 `192.168.1.1` 或 `10.0.0.1` 附近，用体检脚本探测；
4. 同样把该 IP 填进上面两个配置文件。

缺点：一次只能一台设备连；电脑连上后没有公网。**不推荐长期使用。**

> 提示：修改完配置后，务必**重启 `1-启动Seestar后端.bat`** 才生效。

## 五、日常使用流程（逐步）

### 第 0 步 · 体检（每次观测前）

双击 **`0-部署体检.bat`**，确认四项：
```
[OK] seestar_alp .venv
[OK] seestar-mcp .venv
[OK] 已放置 seestar_client_key.pem
[OK] opencode.jsonc 中已注册
[在线] 192.168.20.50:32323      ← 望远镜必须显示"在线"
```
只要有**任何一项离线**，先解决它再往下走。

### 第 1 步 · 启动后端

双击 **`1-启动Seestar后端.bat`**，**保持这个黑窗口开着**。
等到窗口里出现：
```
Startup Complete
```
说明后端就绪（Alpaca 后端 :5555、网页界面 :5432 已开始监听）。

> 此时可以打开浏览器访问 **http://localhost:5432**，这是 seestar_alp 的网页控制台，
> 可以图形化地看设备状态、手动 GOTO、看实时画面。**这个界面同时也是一个很好的"备用遥控器"。**

### 第 2 步 · 用自然语言指挥 Agent

回到 **opencode**（就是你现在跟我对话的地方），直接用中文下指令即可。例如：

> **连接与状态**
> - "连接望远镜，报告当前状态"
> - "现在指向哪里？跟踪开了吗？电池还剩多少？"

> **对焦与准备**
> - "跑一次自动对焦，告诉我焦点位置"
> - "打开除雾加热"

> **拍摄**
> - "GOTO M31，然后开始实时叠加"
> - "切换到 LP 滤镜"
> - "停止叠加"
> - "现在拍一张 10 秒的预览"

> **数据与质检**
> - "列出设备上已拍的原始照片"
> - "对刚才这一轮做一次质检查，有没有拖线/模糊"
> - "生成这次观测会话的报告"

> **规划**
> - "帮我设置观测地点档案：纬度xx，光害等级 Bortle 6"
> - "今晚天气怎么样？适合拍照吗？"
> - "推荐今晚能拍的深空目标，并模拟一整晚的计划"
> - "M42 今晚什么时候能拍、能拍多久？"

> **收尾**
> - "收工，回到停放位"
> - "关闭望远镜"

### 第 3 步 · 结束

1. 让 Agent 执行 "park"（回到停放位）；
2. 确认望远镜已停放后，再物理关机（或用 Agent 的 shutdown）；
3. 关闭 `1-启动Seestar后端.bat` 的窗口。

## 七、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 显示"已连接"但所有命令超时，报 `Unable to get stats.` | **缺 RSA 密钥**（最常见） | 回到第三节提取并放置 `seestar_client_key.pem` |
| 后端启动后日志报连接失败 / 找不到设备 | IP 不对或不在同一网络 | 站模式确认固定 IP；AP 模式确认电脑连了望远镜热点 |
| 体检显示望远镜"离线" | 望远镜没开机 / 不同网段 / 固件在待机 | 用官方 App 先唤醒设备；确认电脑与设备同一 WiFi |
| App 和 Agent 抢连接 | 望远镜只允许一个"主控" | 用 Agent 时**关掉官方 App**（或反之以 App 为主） |
| 长焦模块十几分钟掉线一次 | 固件 9.x 已知问题 | 关掉官方 App 独占；更新到最新固件；重连即可 |
| `park` 后臂没折叠 | Alpaca 的 park 语义在部分固件不可靠 | 以官方 App 确认停放；或先用 App 完成首次初始化 |
| 首次初始化（展开臂）失败 | Alpaca `unpark` 不能可靠展开臂 | **首次初始化请用官方 App 完成**，之后 park/unpark 正常 |
| 想让 Agent 直读设备里的 FITS | SMB 直读默认关闭 | 见下方"进阶" |

## 八、进阶配置

### 8.1 让 Agent 直读设备里的原始照片（SMB）

默认 Agent 通过 HTTP 取图。若想让 `list_subs` / `download_subs` 直接从设备共享读 FITS，编辑 `seestar-mcp\.env`，取消注释并填写：
```ini
SEESTAR_SEESTAR_IMAGE_ROOT=\\192.168.20.50\EMMC Images\MyWorks
```
并**以管理员**运行一次（这是全机器级安全降级，用毕建议改回）：
```powershell
Set-SmbClientConfiguration -EnableInsecureGuestLogons $true
```

### 8.2 天气数据源

默认使用 **Open-Meteo**（免费、无需 key），开箱即用。
`seestar-mcp\.env` 里的 `SEESTAR_METEOBLUE_API_KEY` 为付费计量服务，**建议保持留空**（社区曾有一天烧掉数百万配额的案例）。

### 8.3 调整 QA 画质阈值

`seestar-mcp` 的质检阈值默认按 S50 设定。S30 Pro 画幅不同，若 QA 判定过严/过松，可在 `.env` 中用 `SEESTAR_QA_*` 系列变量覆盖。

### 8.4 无人值守整夜拍摄

seestar-mcp 自带 `slot_watch` 监视器与 `autonomous-night` 技能：
```powershell
uv --directory C:\Users\BGSJIA\seestar-agent\seestar-mcp run python -m seestar_mcp.slot_watch --duration 1740 --every 60
```
配合 `deploy/dawn_park_watchdog.sh`（原为 Linux 设计，Windows 需改造）可实现天亮自动停放。

### 8.5 只用网页界面（不想用 AI 时）

直接浏览器打开 **http://localhost:5432**，用 seestar_alp 的图形界面手动操作，功能完整。

## 十、重要提醒

1. **RSA 密钥已就位**，无需再操作；如更换设备或固件认证失效，按第三节重新提取。
2. **一次一个主控**：望远镜同一时间只接受一个控制端，Agent 与官方 App 不要同时抢。
3. **先 park 再关机**：养成习惯，保护设备。
4. **固件 9.x 波动**：S30 Pro 在较新固件上偶有长焦模块掉线，属已知问题，重连即可，不是你的部署出错。
5. **本方案为开源社区整合**，非 ZWO 官方支持；seestar-mcp 尚处 Alpha，遇到问题可到两个项目的 GitHub Issues 反馈。
