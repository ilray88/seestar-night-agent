## 六、今晚必须避开的 6 个坑

### 1️⃣ 最致命：不要隔玻璃
室内窗台 + 关窗 = 全废：
- 双层玻璃 4 个反射面 → 星点出现重影/彗差
- 室内外温差（29 vs 25°C）在玻璃表面形成对流 → 视宁度崩溃
- 室内灯在玻璃上反射 → 画面鬼影

**必须把窗户完全打开**，或把设备架到窗外/阳台。

### 2️⃣ 关掉房间所有灯
朝北窗户尤其容易被室内光污染。拍摄期间关顶灯、调暗屏幕、拉上背后的门。

### 3️⃣ 窗框会切视场
S30 Pro FOV 仅 3.99°×2.24°。每次 goto 后先拍 5 秒预览，确认窗框、窗帘、防盗网没进画面。

### 4️⃣ 目标会"走出"窗户
窗口固定但天球在转：

| 目标 | 入窗 | 出窗 | 注意 |
|---|---|---|---|
| M31 | 19:00 | **22:40** | 之后转向北，23:50 短暂回窗 |
| IC 1805 | 19:10 | **05:00** | 整晚在窗，最稳 |
| NGC 1499 | 21:10 | 01:25 | |
| M45 | 21:15 | 00:50 | |
| M81 | 02:20 | 05:00 | |

### 5️⃣ 场旋（Field Rotation）
S30 Pro 是**地平式**支架，越靠窗边场旋越快：

| 目标 | 场旋速率 | 判断 |
|---|---|---|
| M1 蟹状 | 3.1°/h | ✅ 极低 |
| M45 昴星团 | 4.5°/h | ✅ 低 |
| NGC 1499 | 8.8°/h | ⚠️ 中 |
| M31 | 11.7°/h | ⚠️ 中 |
| **NGC 2403** | **19.1°/h** | ⚠️ 偏高 |

**对策**：直接用机内叠加出图（固件自动去旋转），**不要保留原始帧后期叠加**——边缘目标旋转明显，后期难对齐。

### 6️⃣ 露水
22:30 后温差跌到 3°C 以下，镜片会起雾。设备放室外就开加热器；放室内窗台（窗户开着）受室内暖空气保护，风险较低。

## 七、怎么操作

### 方式 A：SSC 网页界面（推荐，直观）
1. 双击 `1-启动Seestar后端.bat`
2. 等终端出现 `Startup Complete` 和 `Authentication successful`
3. 浏览器开 **http://localhost:5432/**
4. 左侧选设备 → Connect
5. 点目标 → Goto，等 goto 完成
6. 确认滤镜/增益/曝光 → 点 Stack
7. 拍完点 Stop，换下一个目标

### 方式 B：Agent 对话控制（opencode）
直接对我说，例如：
- 「连接到望远镜」
- 「指向 M31，开始叠加」
- 「切换到 LP 滤镜」
- 「停止曝光，指向心脏星云」
- 「现在状态怎么样」
- 「拍完了，park」

工具名：`connect_telescope`、`goto_target`、`start_stack`、`stop_view`、`set_filter`、`park`、`get_status`、`get_view_state`、`list_subs`。

### 首次开机初始化（今晚第一次）
1. 摘镜头盖
2. 等机械臂自动展开（约 30 秒）
3. 水平校准（内置自动）
4. 自动对焦 AF
5. 确认 GPS 定位（应在龙华）
